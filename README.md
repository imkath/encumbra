# Encumbra v2

Segunda versión de la app de monitoreo de seguridad ciudadana para Chile.

## Mejoras sobre v1

- SafetyIndicator mejorado
- WindowsCarousel para alertas
- Flujo de autenticación
- Preguntas frecuentes y páginas legales
- Mejor arquitectura de componentes

## Stack

- Next.js (App Router)
- Zustand (estado)
- Tailwind CSS

## Correr local

```bash
npm install
npm run dev
```
